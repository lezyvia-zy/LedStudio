整体流程

先有效果，再出代码。工具里把排布和灯效都做出来，导出 C 贴进固件。

  1. 分区 —— 告诉工具「板子分成几块、每块从几号灯到几号灯」。SP-3122D 预设里已经填好。
    这一页还管着板级参数（项目名 / 灯总数）、按形状铺灯（矩形 / 圆角矩形 / 圆环 / 多边形 / 直线， 见下面「按形状铺灯」那一节）和底图（选一张实物照片当参照，照着它描灯位最省事）—— 换一块板从头做，全在这一页里走完。
  2. 效果 —— 做素材：一个效果 = 一套图层 + 配色 + 速度。效果是素材库，可以被任意多个模式、任意多个分区复用。
  3. 模式 —— 把效果分配到分区：一个模式 = 若干条「分区 → 效果」的绑定。模式顺序就是固件的 LEDMode 顺序。
  4. 动画 —— 预览选中的模式（整个板子按绑定跑起来），调速度、单步、归零、方向修正。
  5. 校验 —— 看有没有编号跳号、分区重叠、参数越界这些问题。
  6. 导出 —— 生成 led_effects_gen.h，按里面的补丁说明改固件，烧录。
编辑结果会自动存在浏览器本地，关掉再打开还在。顶栏右侧显示「已自动保存」。

三个概念，别搞混

概念是什么在哪编辑
分区物理灯号的一段，比如 16–55 是顶环。一个分区一条 SPI 链上的连续编号。
表的先后就是板上编号顺序（导出 C 里那张 {start,count} 表也按它排）——要换顺序用左侧「上移 / 下移」， 两段各自几颗灯、形状原样不动，只有编号按新顺序自动重排。		分区页
效果一种动态图案的做法，比如「单点追逐」「绕环彩虹」「呼吸」。与分区无关。效果页
模式一整套「哪个分区跑哪个效果」的分配方案。按键切换的就是它。模式页

举例 —— 你想要的 LED_MODE_1 可以这样配：

分区效果
左旋钮 0–7、右旋钮 8–15慢速渐变色（两个分区选同一个效果 → 自动同步）
顶环 16–55慢速彩虹环
环 A 56–79、环 B 80–103单点追逐（同一个效果 → 同步）
要点：多个分区选同一个效果 = 它们共享一份相位，就是真同步。想要「看起来一样但各自错开」， 就复制一个效果改改参数，让两边用不同的效果。

按形状铺灯（画形状：先挑、再拖、点两下定头尾）

「铺灯」= 给某一段编号（一个分区）决定哪一号灯落在哪、编号怎么走。现在是照画图工具：先挑形状 → 画布上拖出来 → 点两下定头尾。

形状不进固件。导出物只有分区表的 {start, count, reverse}（坐标一个字节都不导）， 所以形状、顶点、灯距怎么调都不会动到固件 —— 它是给你自己看着铺、照着核对的。

三步走：

  • ① 挑形状：在「铺灯 · 形状」的形状选择框里点一个 —— 矩形 / 圆角矩形 / 圆环 / 多边形 / 直线（跟面板「形状类型」下拉是同一套五选一；多边形拖出来默认是正六边形，边数在面板「边数」里改 —— 改完按当前外框重画，外框不变。左侧 S 键进「画形状」模式）。
  • ② 拖出来：到画布上按住一拖，灯沿边框等间距依次排开（这时候不带编号，只报「N 颗 · 灯距 x px」）。 排不下就重叠着 —— 把框拖大到「灯距 ≥ 一格」就排开了；拖形状内部 = 挪动，拖四角/四边的小方块 = 改大小。画完自动松开鼠标。
  • ③ 点形状进编辑、定头尾：点一下刚画好的形状（轮廓，没铺的连内部也算）就进入编辑态，而且按住那一下就能直接拖 —— 抓四角/四边的小方块 = 改大小，按在框里 = 挪动，不用「先点中、松手、再按第二下」。 点空白或 Esc 释放、点其它形状随时切换选中。铺过灯的形状被灯点盖着不好点？三条不用挑位置的入口： 面板「形状」下拉里挑一个、它右边的「编辑」按钮、或者在画布上双击它 （双击点不落在灯点上时才算 —— 连点两颗灯仍然只是选灯，不会被悄悄换成形状编辑态）。 那 8 个蓝色小方块只在「画形状」编辑态里出现：没进编辑态就是一个也看不见、也抓不到 —— 铺灯时不会再莫名其妙把形状拖大/拖走（这是上一版的毛病）。看得见的东西才抢点击。 手差点没抓准也没关系：小方块外那一圈（1.6 倍容差）同样算改大小，不会把整块形状连灯一起挪走。 定头尾是另一件事 —— 它只改这一段编号，不动形状几何，也不算形状编辑（不会把左侧栏切成「画形状」， 那 8 个小方块也不会冒出来）。用法：先在分区表里点中要重排的那个分区，再点「在画布上定头尾」， 然后在画布上点两下 —— 第一下点是头（这一段编号从哪儿开始，头就落在你点到的这一颗上）， 第二下点是方向（只用来定编号往哪边走：离头近的那边走），两点定完自动铺进编号。 第二下不是「把尾定在你点的那一颗上」：最后一颗编号落在哪儿由颗数 / 分布决定 —— 点完这一下状态栏会告诉你「尾」是第几颗、离你点的那颗差几颗（想让尾挪个位置，就改「颗数」或「分布」）。 点「头」那一下已经铺过灯的形状会立刻按新起点重排（能当场看到 1 号落在你点的那一颗上）， 第二下只翻方向、头不会再挪（上一版第二下会连头一起挪走，看着像「头尾反了」）。 这两步里画布上的编号会先藏起来（省得满屏数字看不清该点哪儿），这一段自己的灯会被圈一圈好认； 点完第 1 下只把「头 N」亮出来，第 2 下点完所有编号立刻回来。 在画布窗口的左上角一直写着一行「① 点头 / ② 点方向」（固定在那儿，不跟着形状跑）， 点歪了（没落在这个分区上）不会把你踢出这一步，只提醒一句； 再点一次这个按钮（它这会儿写着「取消定头尾」）或按 Esc 就退出，「头」已经挪过的那一下用 Ctrl+Z 退。

微调单颗灯：选择模式下点在灯上就选中那颗灯（要动形状就点形状的框内空白处，或从面板「形状」下拉里选它）。 把形状里的某几颗灯拖到别处也没关系 —— 它们会记着自己相对形状的位置，之后挪动 / 改大小形状时跟着一起走； 拖回原位附近（约一格内）就自动吸附回形状上。（偏移跟着工程存盘，Ctrl+Z 一样能撤销。）

换形状类型 / 新增空白形状：面板「形状类型」下拉或形状选择框点另一种，形状会按那种类型重画（外框不动， 所以「矩形 → 多边形」一眼看出变化）；换类型、改多边形「边数」都会让挪出去的灯归位并立刻重铺 —— 它俩换的是整套几何，旧的相对偏移没有意义（只想挪动 / 改大小时它们照旧跟着走）。 面板「新增空白形状」会在画布正中起一个 6×5 格的形状（画布缩得小时按屏幕尺寸放大， 至少约 110×90 屏幕 px —— 再小就点不中手柄了），并直接进入编辑态： 四个角 / 四条边的 8 个小方块立刻画出来，按住一个就能改大小（那小方块外一圈也算，手不用那么准）。

下面是四种分布（拖出来的新形状默认「等分弧长」；接老工程 / 贴实物灯带再换别的）：

分布什么时候用
每边颗数实物就是「上面 6 颗、右面 5 颗…」这么焊的。填 6,5,6,4 就行， 最贴真实灯带（各边灯距因此会不一样，属正常 —— 想核对就临时切「等灯距」看灯距那一行）。
等分弧长只想让这 N 颗沿形状均匀铺满，不关心每边几颗。闭环时连最后的缝一起均匀。
等灯距按真实灯距撒点（最像走线）。闭环时诊断行会告诉你「周长 ÷ 灯距 = 21.00 颗 → 正好闭环 ✓」， 差一点就写「差 40px 才回得到起点」，照着把形状尺寸调一格就行。
格点旧的「矩形环绕圈」整数格行为。老工程要一字不差重现原来的排布时用它。

头 / 尾 / 方向：头是这一段编号的第 1 颗（默认取分区 start），方向决定编号顺着形状顶点顺序走还是倒着走， 起点偏移把头沿着路径挪一挪（想让它从某个角开始就填那个角对应的弧长）。画布上这条形状会标出「头 N」（实心点）和 「尾 M」（空心圈）—— 一看就知道编号从哪进、从哪出。 正在定头尾时（点了「在画布上定头尾」那两步）这两个点会先标成不带号的「头」「尾」，「头」还画大一圈； 点完第 1 下「头」就亮出号，第 2 下点完编号全部回来 —— 方向还没定的时候，写数字反而误导。

  • 铺到灯位：按当前形状把这一段编号铺下去（号段上原有灯会先问一句再覆盖，可 Ctrl+Z）。 「没铺过这个形状」时这个按钮是蓝色的 —— 亮着就说明「照现在的形状铺下去」是这一步该做的；铺完就灭了。
  • 反向编号：几何一点不动，只把这一段的编号顺序倒过来 —— 头换到另一头，各分区绕行方向随之翻转。 已经铺过灯的形状不再弹确认框（几何没动、点错了 Ctrl+Z 就退回去了）。
  • 只画不铺：把形状存成参考线，不动任何灯位。
  • 由分区反推：接手老工程时先点它 —— 按现有灯位的包围盒反推一个形状（整数格上能重现旧排布时自动用「格点」档）， 之后就能拖着改了。
举个例子：21 颗要围成一圈闭合。整数格矩形的周长是 2W+2H-4，恒为偶数， 所以「21 颗正好铺满一圈」在老做法里做不到（一定留一个空格当豁口）。现在顶点可以落在半格上： 宽 6、高 6.5 的矩形周长 = 840px，按灯距 40px 正好 21 颗、连缝都等距 —— 分布选「等灯距」、灯距填 40，诊断行会写「正好闭环 ✓」。实物是 6/5/6/4，就把分布改成「每边颗数」。

效果编辑台（基础排布）

效果**和你的真实灯板无关**。在「效果」页时中央画布会切到编辑台 —— 一个通用的基础排布：

  • 直线：颗数可自定义。看追逐的宽度、拖尾、衰减最清楚。
  • 圆环：颗数可自定义。用来看环形效果"绕回来"时的接缝。
  • 多长度对比：同时画几条 —— 取你板子上真实的分区长度（去重后最多 3 条：最短 / 中间 / 最长），板上一段分区都没有时才回落到 8 / 24 / 40。
效果页底部的播放条（钉在这一页底部不动；按钮上只有图标，鼠标悬停看说明） 就地控制这个编辑台 —— 最左边那格方块 = 归零（回到起始相位），中间三格是 上一条 / 播放暂停 / 下一条（把做完的效果从头到尾巡一遍：只换「现在看哪一条」， 不动效果库里的顺序，也不动模式绑定；正播着换下一条接着播）， 右边两格是前一帧 / 后一帧（一个灯位一格，正播着会先暂停），最下面是倍率 0.25×~8×。
「在灯板上看」暂挂起（等「模式」模块完成后回来做）：要对到真实灯板，先去「动画」页 把「预览对象」选成单独一个效果。
为什么需要「多长度对比」？因为效果在各分区上是等比缩放的 —— 张角相同、点亮的颗数不同。同一个光宽 10 的效果：
8 颗的旋钮 → 只有 1–3 颗亮；24 颗的环 → 约 10 颗；40 颗的顶环 → 约 16 颗；104 颗 → 约 37 颗。
所以在一条 24 颗上把宽度调到"刚好"，到 40 颗上就是一片糊、到 8 颗上只剩一根线。 这就是「多长度对比」存在的原因 —— 一眼同时看到最短和最长的那段。

模式页：给某条绑定单独调参数

如果某个分区需要和别的不一样（最常见：8 颗的旋钮光晕太窄），在模式页那条绑定上勾 「覆盖参数」：

  • 勾上会复制一份当前效果作为这条绑定自己的副本，然后点「微调参数」到效果页去改 —— 界面和编辑效果完全一样，但改的是这份副本。
  • 改完点顶部横条的「返回效果库」回到正常编辑。
  • 这套参数只影响这一条绑定，不影响效果库里的原效果，也不影响别的绑定。
  • 导出时这份覆盖会被解析成独立的一行效果，固件那边一行都不用改。
代价：同一个效果如果在好几条绑定里各自覆盖，它们就互相独立了 —— 以后改原效果不会影响它们。 校验页会给出提示（V33）。所以能用原效果就别覆盖，确实需要差异化时再开。

效果页：图层怎么调

页面从上到下：效果库列表 → 编辑台（基础排布）→ 预置效果（一键套模板）→ 图层（自定义动效）（套完就地加 / 调图层）→ 选中效果（名称 / 别名 / 序号 / 类型 / 使能 / 慢速 / 快速 / 起始位）→ 内建参数（只对内建效果出现）→ 色彩配置（配色 / 调色板 / 跳变与彩虹的节奏 —— 这一块在页面最下面）→ 底部常驻播放条。

效果分两类：内建（直接用固件原有的动画类型，参数只有动画 / 光宽 / 间隔 / 配色 / 速度）与自定义 （图层合成；任何一条内建效果都能一键「转为自定义」接着改）。内建里的单点追逐是一条 平顶光带 —— 带内一律最亮、带外全灭、不带边缘衰减（每颗灯只有「减、取绝对值、比较」三步， 主控几乎不花时间）。想要拖尾 / 柔边 / 彗星，把它们做成图层（一个「光点」层 + 衰减曲线）即可。

一个自定义效果由若干「图层」叠加而成，每个灯位取所有图层里最亮的那一个（连带它的颜色）。

效果的名字不用自己起：工具按「模板 / 配色」自动生成 —— 内建的「模板」就是固件动画名 （「单点追逐/单色」）；自定义的「模板」是你最近套用的那个预置模板（套「拖尾彗星」就叫「拖尾彗星/单色」， 套完再调宽度、速度、相位名字都不动；自己从零搭的叫「自定义/单色」）。换模板或改配色，名字就跟着变。 名字只写进导出的 C 注释（ASCII 注释用「别名」那一栏），不进固件数据。

图层卡最左边有个勾选框：取消勾选就是旁路这一层 —— 预览和固件都跳过它，但参数和位置都留着， 想比「少了这层会怎样」时不用删了再加回来（整条效果的层全被旁路，校验页会提示 V37：渲染出来是一片黑）。 旁边的复制把这一层连同参数复制一份插在后面，做「看着一样、错开相位」的变体不用重配一遍。

2026-10-27 起，图层卡上的「相位 / 脉动周期 / 脉动深度」（光点层）和四个「+ 光点 / + 随机闪 / + 填充 / + 亮度渐变」按钮暂时收起 —— 先把每个预置动画调到最好看，自定义叠加与这几项高级参数留到以后专门做。要挪光斑起点用「选中效果 → 起始位」。 注意填充层的脉动仍然在：它是「闪烁 / 跳变 / 呼吸彩虹」三条预置的命脉，不能收 （「闪烁」用的是其中音控闪那一种：没音乐时 5 秒一闪、有音乐时按更短的间隔一直闪，见下表）。

① 光点（spot）—— 沿环跑的光斑

参数作用
光点数环上同时有几个光斑。1 = 单点追逐，2 = 双点，再大就是多点。
光宽光斑有多宽（按 RING_SIZE 逻辑单位，各分区会等比缩放，所以各环张角一致）。
衰减曲线光斑边缘怎么衰减：余弦窗最柔和（固件原版的双点追逐/摆动就是这个）；线性是直上直下；硬边是纯色块（＝平顶光带，内建「单点追逐」画的就是它）；单边拖尾一边亮一边长尾 = 彗星。
方向沿编号正方向跑，还是从环的另一头出发反着跑（整条朝着相反方向走）。
往返选「走到头折返」= 一路走到环的最后一颗灯（绕满一整圈）才掉头，再照原路走回来 —— 一个来回 = 两圈，也就是摆动 / 钟摆；选「绕圈」就是一直朝一个方向追。配合「起始位」可以把掉头的位置挪到环上任意一处。

② 填充（fill）—— 整环一起亮

参数作用
填充亮度整环的亮度。
脉动周期/深度让整环亮度周期性起伏（三角包络：满亮 → 暗 → 满亮）。
要「呼吸」请用配色「呼吸」（平滑曲线 + 一个周期换一种颜色，见下面那张表的「配色」一行）—— 预置「呼吸」套的就是它，两条路各走一半只会让人分不清哪个才算数。
这里留下三角脉动是给「跳变 / 呼吸彩虹」两条预置用的（它们要的是一亮一灭 / 渐暗后跳回那种硬包络）。
闪烁（预置「闪烁」= 音控闪）套了预置「闪烁」的那一层，填充层会多出两格、名字也换了： 没音乐时闪的间隔（= 脉动周期，出厂 250 拍 = 5 秒）、闪完暗到（= 脉动深度，255 = 全灭）， 再加 有音乐间隔（出厂 25 拍 = 500 ms）和 亮的时间（出厂 10 拍 = 200 ms）。
「有没有音乐」用固件那条现成的判据：FFTLevel 大于 LED_FFT_THRESHOLD(=4) 就是有音乐（预览条上那根「音量」滑杆 / 「音乐来了」就是它）。越过阈值那一拍立刻闪一次， 之后只要还在阈值以上就按「有音乐间隔」一直闪；音乐一停就回到「没音乐时闪的间隔」。
参照的是固件老 SPI RGB 灯功能（CFG_FUNC_SPI_RGB_EN → spim_led.c 的 PixelFlash()）：那边是「亮 100 ms + 静音每 4 秒一次 + 超过阈值立刻重触发」， 与 CFG_FUNC_LED_RING_EN 那套无关。

③ 随机闪（twinkle）—— 与位置无关的随机亮度

参数作用
点亮密度大约多少比例的灯同时亮着。数值越大越密。
刷新间隔每几帧换一批灯。
亮度下限/上限亮起来的那批灯在什么亮度区间内随机。

④ 亮度渐变（gradient）—— 沿环的明暗斜坡

参数作用
亮度下限/上限斜坡两端的亮度。
起始位斜坡从环上哪个位置开始。想让暗处对着某个方向时调它。
绕环轮数一圈里有几个明暗来回。
旋转每 N 帧把斜坡推进一格；0 = 不动。

颜色从哪来：只从「色彩配置」来

图层只描述形状（哪几颗灯亮、多亮、怎么动），不带颜色： 图上什么颜色，全看页面最下面那块「色彩配置 → 配色」。想换色就只动那一个下拉， 动画本身一点不用改 —— 这就是动画与色彩分离。 要让每颗灯颜色不同，把配色设成彩虹：它沿灯位铺开、首尾相接， 图层照常跑形状，颜色自己按位置落（「绕环彩虹 / 彩虹光点 / 呼吸彩虹」几个预置就是这么做的）。

以前的「本层取色（空间色相）」已经退休 —— 打开老工程时，带它的效果会 自动迁成效果级「彩虹」配色，图层里的色相起点 / 跨度 / 旋转顺手清掉。 「波形」也不在图层卡上了：脉动固定三角（呼吸），要「一亮一灭 / 渐暗后跳回」请用配色「跳变」。

效果级参数（都在页面最下面的「色彩配置」里）

参数作用
配色 纯色：整条固定用调色板第 1 个颜色。
跳变：调色板里几种颜色轮着来。每种颜色先用「渐亮(拍)」匀速爬到满亮（第一拍就是 255 / 渐亮、最后一拍正好满亮；0 = 一拍照跳，硬启亮），再在「亮(拍)」里保持满亮，然后用「变暗(拍)」匀速暗下去：最后一拍停在 ≈255/(变暗+1)，暗到看不见但不是全黑（全黑一帧在 50Hz 下就是一次闪，换色处会「抖一下」），就在这一拍换下一种 —— 接缝看不出来。「停留(拍)」= 渐亮 + 亮 + 变暗，填那三行时自动算好，不用手填（上限 255 拍）。
渐变：整条同色，随时间在一条颜色环上平滑循环（默认顺序 红→黄→绿→青→蓝→紫→红），快慢由「速度」和「步进」两个数一起定：「速度」= 几拍动一次（1..16，从跳变切过来时会自动收进 4 —— 20 秒一圈，想更慢再往上调）、「步进」= 一次在环上前进几级（一整圈 = 256 × 速度 ÷ 步进 拍）。这条环是你自己存的一套渐变（「渐变-1 / 渐变-2…」）：起始色 = 相位 0 是哪个颜色（等于把整条环转一下，顺序不变）；顺序 = 2~8 个颜色按先后排好，相邻两个之间由算法等长补过渡 —— 只要定几个颜色的大致方向就行。改「起始色 / 顺序」动的是库里那一条（用它的效果一起变）；想再来一条，用「新建」（从零开始：默认顺序 + 起点红，跟库里别的都不搭界）或「另存为」（在这条的基础上复制一份微调），原条都一点不动；再在模式页给某条绑定打开「覆盖参数」、用那张卡上的「渐变」下拉换成另一条。
彩虹：沿灯位铺开、首尾相接的连续彩虹（每颗灯颜色不同）；级数 = 走完一轮红→红要多少颗灯（30 颗的圆环填 30，40 颗的顶环填 40）。
呼吸：暗→亮→暗算一个周期，一个周期换一种颜色（颜色来自调色板）。骨骼就是跳变那套包络，只是渐亮和渐暗一样长、而且走平滑曲线（起步慢、中段快、到顶自然减速）：只填「渐亮=变暗(拍)」和「亮(拍)」两行，「周期(拍)」= 渐亮 × 2 + 亮 自动算好。出厂手感是 40 / 10（1.8 秒一个来回）；20 拍以下会看出一格一格的台阶。同样不落全黑 —— 最暗那一拍停在 ≈255/(渐亮+1)，换色就在那儿发生，接缝看不出「抖一下」。预置「呼吸」用的就是这一套（套完这里就是「呼吸」），所以它就是「呼吸」唯一的定义；调色板里别放纯黑条目 —— 那一个周期整条全灭，看着完全像动画停了（打开老工程时那个占位的纯黑第 2 色会被自动去掉）。
覆盖：连环扫 —— 第 2 个条目从一头把第 1 个盖过去，盖满之后换下一个条目接着盖（不会整条跳回底色）。覆盖方向：往返 = 盖满就从另一头盖回来，来回交替；单向 = 每趟都从同一头重新推过去（像跑马灯从头刷）。一趟多少拍看「速度(拍/趟)」，越小越快。覆盖灯数 = 这一趟最多扫过多少颗灯（0 = 整条分区；40 颗的顶环填 16，就只有前面 16 颗在动，后面的灯一直是初始底色）—— 这就是「覆盖等级」。扫过去是一整块还是渐变，看调色板里那个条目：纯色条目 = 一整块颜色（硬边）；[A→B] 条目 = 沿灯位铺 A → B 的位置渐变（「+渐变」加一个，胶囊左右两半分别选两端的颜色；取色面板底部随时能把一个条目改成纯色、或再改回渐变）。两种条目可以混在一个调色板里，于是同一个模式里有的趟是硬边、有的趟是渐变。
对照看配色套预置「全点亮(测配色)」：一个满亮填充层，不走位置、不脉动、不铺色相 —— 整条常亮，在这里换「配色」就能直接看出六种配色的差别。
渐变（起始色 / 顺序）只在配色 = 渐变时出现。起始色 = 相位 0 显示哪个颜色（= 整条环转一下，顺序不变）；顺序 = 2~8 个颜色，‹ › 换前后、+ − 增删，锚点之间自动等长补渐变；下面那条色带就是整条环的预览（最左 = 起始色，播放时颜色从左往右走）。新建 = 一条全新的（默认顺序 + 起点红，跟库里别的都不搭界），另存为 = 在当前这条的基础上复制一份（渐变-2、渐变-3…），两者都会把这条效果切到新的那条、原条一点不动；删除删掉当前这条（只剩一条时不给删，用到它的效果自动改回第一条）。
调色板用户自己定的一串条目，最多 16 个。纯色用第 1 个；跳变/呼吸按条目个数循环（渐变条目只取左端色）；覆盖也按条目个数轮换 —— 第 r 趟盖第 r+2 个（回绕），所以放 3 个以上每趟就换一种样子。条目有两种形态：纯色（点「+」加，一个色块）和两端渐变（点「+渐变」加，画成胶囊：左半 = 首色、右半 = 末色，各自可点；整条底就是 A→B 的渐变预览）。渐变条目在覆盖里铺成位置渐变，在跳变/呼吸里只当左端那个纯色用（所以「+渐变」和取色面板里那个切换按钮只在覆盖时出现；切到跳变 / 呼吸时，原来的渐变条目按左端色画成普通色块，数据不丢，切回覆盖又是胶囊）。渐变（颜色环）不用调色板。
取色面板点任何一个色块（调色板 / 渐变起始色 / 渐变顺序 / 分区颜色）都弹同一个面板：色环上点或拖 = 直接选色相（出来就是满饱和、满亮度 —— 灯珠要的就是这种纯色，环顶红 → 顺时针黄、绿、青、蓝、紫；当前色是黑 / 灰时会先把亮度和饱和提满，否则换色相也看不出变化）；要灰、要暗、要白，才展开「▸ 高级设置」里的二维色图（横轴 = 饱和，最左是灰；纵轴 = 亮度，最下是黑），或者在色号框里直接敲 #RRGGBB（#0f0 这种三位简写也认）。点面板外面 / 按 Esc / 再点同一个色块收起；改一下立即生效，拖着的时候编辑台 / 灯板当场跟着变。
级数彩虹专用：多少颗灯走完一轮红→红。最小 6；填成分区灯数 = 这个分区正好一整圈。
色相起点 / 彩虹旋转彩虹从哪个色相开始；每 N 拍整体转一格（0 = 不转）。
周期(拍)呼吸：自动 = 渐亮(=变暗) × 2 + 亮（只读，改上面两行就自己算好）；覆盖：一遍颜色盖过去多少拍。
停留(拍) / 速度(拍)跳变：自动 = 渐亮 + 亮 + 变暗（填那三行就填好，只读）；渐变：每 N 拍沿色环往前一格（1..16，越小越快；一整圈 = 256 × N 拍 —— 1 = 5.12 秒、4 = 20 秒、16 = 82 秒）。再快就要靠下面的「步进(级)」。
切到渐变时会自动收进 4：这一格在跳变下是「停留」（常是 30~60），带过来一圈要好几分钟、看着像「渐变没生效」，所以切过去那一刻会压到 4（20 秒一圈）并在状态栏说明；想更慢再自己往上调（上限 16）。
步进(级)渐变专用：每动一次在色环上前进几级（1..16，默认 1）。「速度」最小是 1 拍 —— 想比「1 拍 1 级」更快就抬步进：速度 1 + 步进 8 = 32 拍 ≈ 0.64 秒一圈（50Hz 一拍 20ms），最大 16 ≈ 0.32 秒一圈。下面那行灰字实时算「一整圈 = 多少拍 / 多少秒」。只改颜色走多快，不动起始色 / 顺序。
渐亮(拍) / 亮(拍) / 变暗(拍)跳变专用：匀速爬到满亮用几拍（第一拍 = 255 / 渐亮、最后一拍正好满亮；0 = 硬启亮，一拍照跳）；满亮保持几拍；再用几拍匀速暗下去（数值越大越慢；最后一拍 ≈255/(变暗+1) 不完全黑 —— 全黑一帧就是一次闪，换色会抖一下；0 = 立刻换色）。三段加起来就是「停留(拍)」（最多 255 拍）。
呼吸只出现前两行：渐亮 = 变暗（对称），「亮(拍)」照旧，周期自动 = 渐亮 × 2 + 亮。
慢速 / 快速每走一格要几帧。数值越大越慢。播放时用「快速」看效果，实际产品里会按音量自动切换。
起始位把整个动画沿环挪一段。想让光点从某个位置出发时用它。
随位置前进勾上 = 这个效果会随时间自己跑（追逐、摆动）；不勾 = 位置不动。

模式页怎么用

  1. 点「新建」加一个模式，或者选中已有的改。
  2. 点「+ 添加绑定」，选一个效果、勾上要跑这个效果的分区。
  3. 重复，直到每个分区都被分到。没被勾到的分区会黑着。
  4. 「按分区拆开」能把一条绑定拆成每个分区一条，方便逐个指定；每条绑定右边还有「全选 / 全不选」。
  5. 「在灯板上预览」直接跳到动画页，按这个模式在真实灯板上跑一遍（不改工程里的分配）。
  6. 「上移/下移」调模式顺序 —— 顺序就是固件里 LEDMode 的顺序。
一个分区不应该出现在两条绑定里（会以先出现的那条为准）。「全选」= 覆盖全部分区（以后加分区也能自动跟上）；「全不选」= 这条一个分区都不跑，那个分区会黑着。

预览页（动画）

预览有两种对象，用「预览对象」切换：

预览对象看什么
按模式跑模式页配好的分区分配 —— 也就是固件里按模式键切过去的样子。看「整块板子配起来对不对」。
单独一个效果把选中的效果铺到所有分区上 —— 单看这个效果本身长什么样。做效果时用这个，不用先建模式。
两处预览各跑各的：效果页的编辑台播放和这里的灯板播放互不影响 —— 在效果页按下播放，这页的灯板不会跟着动；在这里暂停，也不会影响效果页的编辑台。 在效果页改参数也不会重置这里的动画进度。
在效果页就能看：效果页的「播放」是就地播中央那个编辑台，不用跳页 —— 边改参数边看结果。「速度档 / 音量 / 音乐来了」在页签下面那条常驻「预览条」里， 效果页与这一页共用同一份：在任意一页拖音量，两边的档位一起变（效果页看基础动画本身， 这一页看整板映射之后）。要对到真实灯板，就在上面把「预览对象」选成单独一个效果、再选好那一条 （效果页原来那个「在灯板上看」按钮暂挂起，等「模式」模块完成后回来做）。
单独预览只是看，不会改动工程里任何模式的分区分配。
控件作用
选哪个选要预览的模式 / 效果。
速度档 / 音量（预览条）在页签下面那条常驻条里，效果页与这一页共用同一份。速度档是固件里的快慢两档；「自动」= 跟着音乐：音量滑杆就是固件里的 mainAppCt.FFTLevel，大于阈值 4 切快档、小于等于 4 走慢档（见下）。
播放倍率只影响这一页的灯板预览（效果页的编辑台有它自己那一条倍率），不改导出参数。
播放 / 单步 / 归零单步走一格（固件的 speed_cur 个节拍），归零回到起始帧。
方向修正关 = 当前固件的真实表现；开 = 按各分区实际绕行方向反向映射（配 reverse 补丁后的表现）。它下面那行会显示每个分区此刻亮到几号灯。
显示编号 / 圆圈灯位 / 方向箭头 / 动效帧 四个开关，播放中也能随时切。
「自动」速度档 / 音量 / 「音乐来了」按钮（都在页签下面那条预览条里，效果页也看得见、也能拖）：这是老 SPI RGB 灯功能 （CFG_FUNC_SPI_RGB_EN）本来就有的联动，与 CFG_FUNC_LED_RING_EN 那套无关 —— 固件 spimled_service.c 每 20ms 调 ring_set_audio_level(&g_ring, mainAppCt.FFTLevel)：FFTLevel 大于 LED_FFT_THRESHOLD(=4) 就切快档，小于等于就慢档。
「音量」滑杆就是 FFTLevel 本身：拖到 4 以下是慢档，5 以上是快档 —— 拖一下就能看到 同一段动画突然变快 / 变慢（在效果页拖，编辑台当场换档，不用先按播放）；打补丁后 ring_tick() 被 led_gen_tick() 取代， 写 ring->speed_cur 的仍然是它，生成代码每拍从这个 ring 级档位同步进各实例。
点「音乐来了」= 模拟音乐一直在放：播放时 FFTLevel 按鼓点自己跳（重音冲高 → 余音衰减）， 动画就会跟着忽快忽慢。预览和导出的代码走同一条判档逻辑（只有「快档确实更快」时才认快档）， 在这里看到的快慢就是样机上的快慢。

导出与固件

导出都在一个独立窗口里做：在「导出」页签点「动效头文件…」「排布表 C…」「HAL 接口…」「导出 JSON…」把它打开。 窗口可以按住标题栏拖动、从右下角拉伸，Esc 或点窗口外面就关掉 —— 它不占右侧栏，也不挡画布。

窗口里有四个页签：动效头文件（led_effects_gen.h）、排布表 C（g_default_zones[]）、 HAL 接口（led_gen_hal.h，平台要实现的那几个函数）、工程 JSON（整份工程，备份 / 换机器用）。左上角选好形式与注释，下面就是结果，改选项会自动重算。

存文件点「保存到文件…」：Chrome / Edge 会弹系统「另存为」，目录和文件名都能自己选； 其它浏览器退回「下载到默认目录」，状态栏会说明。想直接贴进编辑器就用「复制」。

工具是唯一真源：参数、查表、引擎都由工具生成，平台只实现 HAL 那一层（帧发送 / 音量 / 亮度 / 分区开关 / 毫秒计数）， 并按 20ms 调一次引擎。平台侧写 #define LED_GEN_HAL_IMPLEMENTS 1 后，与工具契约版本不一致会编译期直接报错 —— 所以「固件按工具的需要改」这件事有编译器兜底。完整契约（谁拥有什么、路线、账本）见 docs/firmware-contract.md。

  • 形式：独立头文件 / 粘贴块（补丁指引）/ 两者。
  • 注释：默认 ASCII，最安全。选中文注释时，贴进 SDK 后必须在编辑器里存成 ANSI/GBK，否则乱码。
  • 换行：目标文件是 CRLF，默认就对。

生成的头文件末尾带一段一次性补丁说明，列出要在固件里改的那几处（原文按约定注释保留、别删）。 打完那一次之后，以后再改灯效或改绑定，只需要替换这一个头文件。

效果数超过 9 个时，导出页会多给一段：模式键的回绕要一起改，否则按不到后面几个模式。 数码管显示模式号那段工具不管，得你自己改。

常见做法

想要怎么配去做
呼吸灯效果页「模板」里直接套呼吸（= 静态 + 配色「呼吸」；暗→亮→暗，出厂 渐亮 40 / 亮 10 ≈ 1.8 秒一个来回）。想让每个周期换一种颜色，就在调色板里多加几个颜色（或直接套「多色呼吸」）。
闪烁效果页「模板」里直接套闪烁 = 音控闪：没有音乐（或音乐信号小）时每 5 秒闪一次；有音乐（FFTLevel > 4）时间隔变短、每 500 ms 闪一次；一直很吵就一直按这个节奏闪。三个数都在图层卡上：没音乐时闪的间隔（250 拍 = 5 秒）、有音乐间隔（25 拍 = 500 ms）、亮的时间（10 拍 = 200 ms）。
彗星拖尾一个光点层，衰减曲线选单边拖尾，光宽调大一点。
摆动一个光点层，往返选走到头折返。
绕环彩虹一个填充层，配色选「彩虹」（级数填成分区灯数）；想让彩虹转起来，再调「彩虹旋转」。
一整圈首尾相接的彩虹效果级配色选彩虹，级数填这个分区的灯数（30 颗圆环填 30；填 30 而分区只有 8 颗，就只显示红→黄那一小段）。
一种颜色盖过另一种配色选覆盖，调色板第 1/2 个分别是底色和盖上去的颜色，周期管盖得快慢。
彩虹在跑外环用「彩虹环」（填充 + 效果级配色「彩虹」），顶环再加一个光点层让亮点扫过。
随机闪一个随机闪层；想让它盖在底色上，再垫一个低亮度的填充层。
旋钮光晕太窄模式页那条绑定勾「覆盖参数」→「微调参数」→ 把光宽调大（效果页的「多长度对比」用的是你板子上真实的几条长度，先在编辑台看清再改）。
两个分区要错开相位给其中一个分区单独勾「覆盖参数」，把「起始位」改一下。
沿环渐变呼吸亮度渐变层（绕环 1 轮）+ 一个填充层配脉动。
21 颗要围成一圈闭合分区页：形状类型选矩形，宽 6、高 6.5（周长 840px），分布选等灯距、灯距 40 —— 诊断行写「正好闭环 ✓」。实物是 6/5/6/4 就把分布改成每边颗数。
接手一个老工程分区页点「由分区反推」：按现有灯位的包围盒生成一个形状（能原样重现旧排布），之后改形状、调头尾都方便。
