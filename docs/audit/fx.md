> **配色内核（2026-10-17）**：效果级配色改成 6 种 —— **纯色 / 跳变 / 渐变 / 彩虹 / 呼吸 / 覆盖**，颜色用 `palette`（≤8 个）；彩虹的 `levels` = 走完一轮红→红要多少颗灯（≥6，填成分区灯数就是每个分区一整圈）。纯色 / 渐变 / 呼吸**每帧只算一次颜色**，只有彩虹（q/r 递推，无除法）和覆盖（`0xFE` 哨兵，1 次比较）碰像素；**跳变**除了换索引还乘一个亮度包络（`stepEnv`：前 1/8 停留快速点亮、其后匀速渐灭到灭，换色那瞬灯已黑到底，所以不硬切 —— 停留越短亮灭与切色都越快）。跳变 / 呼吸 / 覆盖的颜色个数就是调色板色块数。**调色板按模式收口**（`palFixed()`）：纯色只显示 1 个色块、覆盖只显示前 2 个，多出来的只是「收起」—— `palette` 数据不动，切回跳变 / 呼吸原样回来；`+` / `−` 只在颜色个数由用户决定（跳变 / 呼吸）时才给，覆盖还差第 2 色时留一个 `+` 补齐。老的 `COLOR_GRADIENT`（相位 +85 的「双色渐变」）退休但保留读法；图层上的「本层空间色相」保留为老存档 / 老预置的覆盖路径（`hue_spread` 仍是 0..255 跨度，不跟新 `levels` 混）。`test_effects_c_exec` 新增 4 种模式的 C/JS 逐字节比对 —— 预览与固件仍然严格一致。
>
> **暂停样本帧（2026-10-17 同日）**：编辑台默认暂停，`stageSampleFrame()` 会把预览实例拨到一帧「看得出区别」的相位（呼吸 = 包络顶点 / 覆盖 = 半程 / 跳变 = 首个非黑颜色 / 渐变 = 相位 85 的绿），`fxStruct()` 也补了 `stageRefresh()` —— 否则套预置、增删图层后画的还是 `stageSync()` 里那份旧快照，看着就像「改了没生效」。`stageSync()` 同时改用 **`editTarget()`** 建实例（微调绑定「覆盖参数」时画的是那份覆盖，不是库里 id 相同的原效果），缓存键带 `eff:` / `bind:` 前缀。**按播放必须从 tick 0 开始**：`stageToggle()` 先落 `stagePlaying` 再 `stageSync()`，别把样本帧带进播放。（用户原话：「修改配色方案，似乎没有立即生效。」）
