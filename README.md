# LedStudio

LED 灯效设计与代码生成工具。**一个 HTML 文件，离线可用，无需安装任何东西。**

双击 `led_layout_editor.html` 就能用（Chrome / Edge 均可）。

## 它做什么

```
① 画排布            ② 编灯效               ③ 生成代码
   分区 + 编号  →   效果（素材库）   →   C 头文件 + 固件补丁说明
                    模式（分配）          ↓
                                    贴进固件、烧录
```

核心是三层，别搞混：

- **分区** —— 物理灯号的一段（比如 16–55 是顶环）
- **效果** —— 一种图案的做法（追逐、彩虹、呼吸…），**与分区无关**，是个素材库
- **模式** —— 一套「哪个分区跑哪个效果」的分配；按键切换的就是它

多个分区选同一个效果时，它们**共享相位（真同步）**；要让某个分区不一样，在那条绑定上勾「覆盖参数」。

## 快速上手

1. 打开工具，顶栏已经带了 **SP-3122D** 的预设（104 颗灯、5 个分区）。想从零做，点左侧「新建」——**「分区」页**里就能改**项目名 / 灯总数**、按**形状**给选中的分区铺灯 —— 照画图工具：在「铺灯 · 形状」里挑一个形状（**矩形 / 圆角矩形 / 圆环 / 多边形 / 直线**，与「形状类型」下拉同一套），到画布上**拖出来**（灯沿边框等间距排开，排不开就重叠着，把框拉大到灯距 ≥ 一格；画完自动松开鼠标），再**点这个形状**进入编辑、在它边上**点两下定头尾方向**（第一下点「头」、第二下点「尾」，画布上会写着现在该点哪儿，点完「头」就已经按新起点重排给你看）；改分区**灯数**时已铺形状会**自动增减灯**。形状与顶点**不进固件导出**，见帮助页「按形状铺灯」）；分区表里还有**「上移 / 下移」**（把相邻两个分区整段换位 —— **灯数与形状原样不动，编号按新顺序自动重排**；选中的是头/尾那一条时对应按钮会灰掉）、**「复制分区」**（同长度分区一次生成，`start` 自动往后排）和**「压缩编号 0..N-1」/「补一个缺号」**（收拾缺号、消除校验页的 `V2`）；改 `start`/`count` 时**字段旁就地报冲突**（`V5`/`V8`/`V9`/`V26`，与校验页同一套码），不用再切页（**数字框可以整段删掉重填** —— 空着不点别处就等于没改）；还能选一张**实物照片当底图**照着描灯位。（`RING_SIZE` / `ZONE_MAX` / `ZONE_MAX_LEN` 是固件的 `#define`，页面上只显示、不给改。）
2. **效果页**：这里是编辑台（一条直线 + 一个圆环，颗数可设），跟真实灯板无关，专门用来调效果。**所有时间参数都按 ms 填**（慢速/快速/渐亮/亮/变暗/停留/周期/脉动周期/刷新间隔/旋转/彩虹旋转…）：内部仍按固件 20ms 一拍计算，填的 ms **一律向上取整**到整拍（填 30 → 40），离开格子就回显实际生效值。
   - 上面有一排**预置模板**（单点追逐/拖尾彗星/摆动/呼吸/闪烁/绕环彩虹/沿环渐变/随机闪/彩虹环/七彩跳变/颜色覆盖/**全点亮(测配色)**…），一键套用再改。**「全点亮(测配色)」**是给配色当底片的：整条满亮、完全静止（不走位置 / 不脉动 / 不铺色相），套上它再换**配色**，六种配色的差别一眼看完；色板里预置了 6 种颜色，切到跳变 / 呼吸立刻就是六色轮转。
   - **页面从上到下**：效果库列表 → 编辑台（基础排布）→ **预置效果**（一键套模板）→ **图层（自定义动效）**（套完就地调这一层的形状参数 —— 光点数 / 光宽 / 间距 / 衰减 / 方向 / 往返；「+ 加图层」暂时收起，先把每个预置调到最好看）→ 选中效果（名称 / 别名 / 序号 / 类型 / 使能 / 慢速 / 快速 / 平滑 / 起始位）→ 内建参数（只对内建效果出现）→ **色彩配置**（配色 / **渐变**：起始色 · 顺序 · 多套保存 / 调色板 / 节奏，全在页面最下面这一块）→ 底部常驻播放条。这一页的中央画布**只预览动画**（不能选灯 / 挪灯 / 画形状 / 放置 / 擦除，滚轮也不缩放；左侧那排「画布工具」会**整块收起**），布局请切到**「分区」页**。
   - 「色彩配置」里的**配色**有 6 种：**纯色**（只用 1 个颜色 —— 选纯色时调色板只显示 1 个色块，多的收起不丢）、**跳变**（几种颜色轮着来：每种先**匀速渐亮**「渐亮(拍)」拍（第一拍 = 255 / 渐亮、最后一拍正好满亮；0 = 一拍照跳、硬启亮）、再**满亮**「亮(拍)」拍、然后用「变暗(拍)」拍**匀速暗下去** —— 最后一拍停在 ≈255/(变暗+1)，暗到看不见但**不全黑**（全黑一帧在 50Hz 下就是一次闪，换色处会「抖一下」），就在这一拍换下一种，接缝看不出来；「停留(拍)」= 渐亮 + 亮 + 变暗，填这三行时**自动算好**填在那一格，不用手填，上限 255 拍）、**渐变**（整条同色、随时间在一条**颜色环**上平滑循环：默认顺序 红→黄→绿→青→蓝→紫→红；**起始色**与**顺序**都能改，还能另存成「渐变-1 / 渐变-2…」多套 —— 效果页「色彩配置」里选一套，模式页给某条绑定打开「覆盖参数」就能换成另一套，不同分区各走各的）、**彩虹**（沿灯位铺开、首尾相接，**级数** = 走完一轮要多少颗灯，30 颗的圆环填 30）、**呼吸**（暗→亮→暗算一个周期，一个周期换一种颜色；骨骼是跳变那套包络，但**渐亮 = 渐暗**、而且走**平滑曲线**（起步慢、中段快、到顶自然减速 —— 看着是「一口气」，不是一格一格跳）：只填「渐亮=变暗(拍)」和「亮(拍)」两行，「周期(拍)」= 渐亮 × 2 + 亮 自动算好、不用手填；出厂手感 40 / 10 = 1.8 秒一个来回，20 拍以下会开始看出台阶；同样**不落全黑**，换色处不「抖一下」）、**覆盖**（**连环扫**：一种颜色从一头把另一种盖过去，盖满之后换一种颜色接着盖 —— 不是盖满就整条跳回；**条目按趟轮换**：第 1 趟盖第 2 个、第 2 趟盖第 3 个……放几个轮几个（最多 16 个，至少 2 个），上一趟盖的那个条目正好是这一趟的底；「**覆盖方向**」= **往返**（盖满就从另一头盖回来）/ **单向**（每趟都从同一头重新推过去），「**速度(拍/趟)**」= 一趟多少拍，「**覆盖灯数**」= 这一趟最多扫多少颗（0 = 整条，这就是「覆盖等级」），**扫过去是一整块还是渐变，看那个条目本身** —— 纯色条目 = 硬边；点「**+渐变**」加的两端渐变条目 = 沿灯位铺 A→B 的位置渐变（胶囊左右两半分别选两端色，取色面板底部还能在纯色 / 渐变之间来回切），一个调色板里两种条目可以混着放）。颜色用调色板定，跳变 / 呼吸 / 覆盖最多 16 个条目。
   - 这一页**底部有一条常驻播放条**（**钉在页面底下纹丝不动**，怎么翻都在；**按钮上只有图标**，鼠标悬停看说明）：最左边那格**实心方块 = 归零**（回到起始相位），中间三格是 **上一条 / 播放暂停 / 下一条**（**实心双三角**照着音乐播放器的上一曲 / 下一曲；把做完的效果**从头到尾巡一遍**做整体预览 —— 巡览只换「现在看哪一条」，**效果库的顺序与模式绑定都不动**；正播着换下一条接着播），右边两格是 **前一帧 / 后一帧**（**一次 = 1 个固件节拍 20ms**：慢档 8 拍才走一格，所以能一帧帧看到平滑的中间帧；正播着会先暂停），最下面是**倍率** 0.25×~8×。条上写着「现在看 XXX · 第 x / n 条」。
   - 想对到真实灯板，去**「动画」页**把「预览对象」选成**单独一个效果**、再选好那一条（效果页原来那个「在灯板上看」按钮**暂挂起**，等「模式」模块做完再回来做）。想直接看**某个模式**：在模式页选中它、点「**在灯板上预览**」—— 按它自己的分配切到动画页开播（改的是「预览对象」，工程里的分配一条都不动）。
   - 打开**「多长度对比」**：画面上会**按你板子上真实的分区长度**各画一条（去重后 1–3 条，标签写着是哪个分区；板上一段分区都没有时才回落到 8 / 24 / 40）—— 同一个效果在不同长度的灯带上长得不一样（等比缩放），调宽度时务必开着它。
   - 效果条数多了，用列表上方的**「过滤」**框按名字 / 类型 / 槽号把它缩出来（**只影响显示**：槽位、顺序、模式绑定一条都不动，清空输入框就全回来）。
- 效果的**名字不用自己起**：按「**模板 / 配色**」自动生成 —— 内建的模板是固件动画名（「单点追逐/渐变」），自定义的模板是你最近**套用的那个预置模板**（「拖尾彗星/纯色」；套完再调宽度、速度、相位名字不变，自己从零搭的叫「自定义/纯色」）。换模板或改配色，名字跟着变；名字只写进导出的 C 注释。
3. **模式页**：新建一个模式 → 「+ 添加绑定」→ 选效果 + 勾分区。重复到每个分区都分到。分区多时用每条绑定上的「**全选 / 全不选**」；想把一条绑定摊成每个分区一条（方便给每个分区单独换效果），点它自己的「**按分区拆开**」，或选中模式后点「**在灯板上预览**」直接看整体。
4. **动画页**：预览整个模式在真实灯板上的样子。速度档 / 音量 / **阈值** / **采样·阻尼** / 「音乐来了」在**页签下面那条常驻「预览条」**里 —— 选**「自动（跟着音乐）」**，拖音量（= 固件 `mainAppCt.FFTLevel`，刻度 **0..最大**：出厂 20，预览条上「最大」格可按板子的实际范围改），高过**阈值**才切快档；阈值**可调**：拖音量滑杆上那根**竖针**、或改旁边的**「阈」格（0..最大，出厂 4）** —— **阈值不能大于最大值**（填超了会夹住并提示，把最大值调小时超过的阈值也会一起压下来）。切档是**带阻尼**的：每 **40ms** 采一次样，采到就**立刻**进快档，然后至少保持 **450ms（向上取整 460ms）** 才允许回慢档 —— 「慢→快干脆、快→慢有惯性」，这个数在预览条上可调（采样固定 40ms，固件那边定死）；**出快档还有一段「过渡(ms)」**（默认 350ms，0 = 直切）把每格拍数缓缓爬回慢档，配合**双阈值**（进 > 阈值、出 ≤ 阈值−1）就不会在阈值附近抽。它们都**随导出写进 C**（`LED_GEN_AUDIO_MAX` / `LED_GEN_FFT_THRESHOLD` / `LED_GEN_AUDIO_SAMPLE_MS` / `LED_GEN_STAGE_HOLD_MS`），固件照它判档，不用再手改宏。点**「音乐来了」**= 每 20 ms 随机注入一个音量（底噪 + 随机鼓点 + 余音，跟板上真实音乐一个脾气），再点一下取消、音量回到 0。**这条预览条在效果页也有**：在效果页拖音量，编辑台当场换档，不用先按播放。音源可选**随机 / 麦克风 / 电脑声音 / 音频文件**，右边「音乐来了」就是**一个开关**：打开就有信号、关掉就没有（开着换音源会立刻换过去）。**音频文件**选一个 mp3 / wav（或直接拖到预览条上）就循环播放——**零授权、零弹窗**，关掉只是暂停（换项目 / 刷新才要重选）——加载后**画布右上角会出现播放条**（▶/⏸、时间、进度，点进度条跳转；暂停只停音乐、灯仍按慢档走；右边「换」/「×」= 换文件 / 关闭文件），项目信息（项目名 · 灯数）挪到了**画布左下角**。真声音会请求一次授权，「电脑声音」要共享一个标签页 / 屏幕并勾「分享音频」—— **共享会保持住，反复开关不会再弹共享框**（换音源 / 换项目 / 停止共享才断开）。响度按 -60dB..0dB 映射到 0..最大值。预览条「刻度」行还能选**「响应：节拍 / 响度」**——**节拍**（默认，低频 + 频谱突变，跟着鼓点、自动按最近峰值归一化）/ **响度**（平均音量，老行为）—— **只用于预览，导出物一点不变**（板上仍由 `led_gen_hal_audio_level()` 给音量）。
5. **导出页**：点「动效头文件…」打开**独立的导出窗口**（可按住标题栏拖动、右下角拉伸，Esc 或点窗口外面关闭）—— 里面生成 `led_effects_gen.h`，带一份**固件补丁说明**（照它改一次固件即可）；旁边的页签还能看**排布表 C**、**HAL 接口**（平台要实现的那几个函数）和整份工程 JSON。点**「保存到文件…」**：Chrome / Edge 会弹系统「另存为」，**目录和文件名都能自己选**；其它浏览器退回下载到默认目录（状态栏会说明）。

界面里每个可调项**鼠标停一下**都有小窗说明；右侧还有个**「帮助」页签**有完整教程。

## 编辑结果存在哪

- 自动存在**浏览器本地**（关掉再打开还在），顶栏右侧显示「已自动保存」
- 「保存工程」导出成 JSON 文件，可以备份、换机器（导出窗口的「工程 JSON」页也能存，文件名默认带项目名）
- 支持**多个项目**，左侧栏可自由切换，互不影响

> 如果浏览器禁用了本地存储（隐私模式），顶栏会提示，改用「保存工程」即可。

## 固件那边

**工具是唯一真源**：参数、查表、引擎都由工具生成；平台只实现一层 HAL（5 个函数）并按 20ms 调一次
`led_gen_tick()`。接口产物是导出窗口「HAL 接口」页签给出的 **`led_gen_hal.h`**（平台侧写
`#define LED_GEN_HAL_IMPLEMENTS 1`，与工具契约版本不一致会**编译期报错**）。

契约全文、平台要实现什么、路线（① 契约先行 / ② 引擎自洽化 / ③ 参数头 / ④ 多后端）见
[docs/firmware-contract.md](docs/firmware-contract.md)。**过渡期**这版 `led_effects_gen.h` 还需要一次性的
固件补丁（导出窗口的「形式 → 粘贴块」给出前后对照）；补丁打完，以后改灯效只需要替换这一个头文件。

## 从固件源码重抽查表

工具里的查表（余弦窗、缓动、彩虹表）和 9 个内置效果**必须与目标固件逐字一致**，手抄必错。用脚本抽：

```bash
python tools/extract_fw_tables.py --sdk ../LED_Optimize/MVsB1_BT_Audio_SDK_v0.3.4 --fixture --js
```

- `--fixture` 重生成 `tests/fixtures/fw_g_presets.txt`（回归锚点用）
- `--js` 输出一段 JS，替换 `led_layout_editor.html` 里 `Object.assign(FW, {...})` 那一块

源码是 GBK，脚本按字节读、按 gbk 解码，中文注释坏了也不影响（要的是数字）。
